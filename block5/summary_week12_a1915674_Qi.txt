Problem4: HouseBuilding
This problem requires us to level an entire region with the minimum total cost. Each +1 or -1 operation costs 1 unit, and the input is guaranteed to be a grid containing only numeric characters ('0'–'9'), where each character
represents the height of the cell. If the difference between the highest and lowest heights in the final grid does not exceed 1 (i.e., max − min ≤ 1), it is considered "leveled".

My approach is to find a value h, where the minimum cost to change the height a of each cell is to change it to the closer value between h and h+1. The corresponding cost per cell is: min{|a−h|, |a−(h+1)|}.
By iterating through all cells and calculating the sum of the costs, we obtain the total cost for the target interval {h, h+1}. The minimum cost among all h values is the answer.

Since the input height is between 0 and 9, I only need to enumerate h ∈ {0,1,…,9}. For each h = 0..9, I iterate through all cell heights a and accumulate min{∣a−h∣, ∣a−(h+1)∣}. I record the minimum total cost using a global
 minimum and return the global minimum.

Problem6: RunLengthEncoding
The solution is straightforward: iterate over the string. If a character is a digit, treat it as the repeat count for the next letter; if it’s a letter, append it to the output using the most recent count (default 1) and then reset the count.
