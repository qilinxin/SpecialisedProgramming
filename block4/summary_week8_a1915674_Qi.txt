3. Discuss how you approach the problem and how you solve the problem.
question1:
1. First step is to sort the existing array from small to large.
2. Find the critical point between addition and subtraction
In the previous step, all the cats were arranged from left to right. Each cat must move X, so the only options are "original position - X" or "original position + X." To minimize the difference,
I need to find a split point k: at which all cats to the left of k move right, and at k and its right, all cats move left. My solution is to try k from 0 to n. Each time, I linearly scan the new positions
of all cats, recording the minimum and maximum values. The difference between these values is the result. The minimum value among all k is the answer.
3. Test and verify the results

question2:
My solution to this problem is to first define a custom node and create nodes for all nodes numbered i.
Second, create a corresponding tree based on the node, attaching node i to its parent node based on parent[i]. The subscript where parent[i] == -1 is the root.
Third, retrieve the result. If the deleted node is the root, return 0. Otherwise, perform a DFS from the root: skip the entire tree if a deleted node is encountered;
recursively count the number of leaves for each child node; if the current node has no "still existing" children, it is a leaf node.
Finally, summarize the results.

question3:
My solution is as follows: first play ff, then use fs to transition to ss, and finally alternate sf and fs until one of them is 0. Based on this, use conditionals to make judgments to get the final result.
If there is no song that begins with f, then start with ss and end with sf

question4:
My approach: First pass: Collect the original order of the A/Z sequences.
Store all A/Z sequences in the azArray, from left to right.
Second pass: Write the A/Z sequences back from right to left.
Because writing back is from right to left, while reading the azArray is from left to right, the first A/Z sequence collected is placed in the rightmost A/Z sequence,
and the second in the second-to-last... This effectively reverses the order of all A/Z sequences; non-A/Z sequences remain unchanged (they are not overwritten).
Finally, the result is returned, converting the modified spellArray into a string and returning it.
